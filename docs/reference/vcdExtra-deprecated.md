# Deprecated functions in vcdExtra

These functions are provided for compatibility with older versions of
vcdExtra and will be removed in a future release.

## Details

- [`Summarise()`](https://friendly.github.io/vcdExtra/reference/Summarise.md)
  is deprecated in favor of
  [`LRstats()`](https://friendly.github.io/vcdExtra/reference/LRstats.md),
  which provides the same brief model-fit comparison under a name that
  doesn't near-collide with
  [`dplyr::summarise()`](https://dplyr.tidyverse.org/reference/summarise.html).
